# RiryTools

Source of `com.riry.rirytools`, editor-only workflow tools for Unity 2022.3 LTS.

- [`com.riry.rirytools`](com.riry.rirytools): the package. [Tools](docs/About/Tools.md) describes every tool.
- [`docs`](docs): tutorials, the [tool list and changelog](docs/About) and the [variable reference](docs/variables.md).

Install it from the VRChat Creator Companion: **Settings > Packages > Add Repository** and enter
`https://rionquosue.github.io/rirytools_vpm/index.json`.

Every push to `main` is published there as a new version, and every push to `beta` as a
beta, by [Rionquosue/rirytools_vpm](https://github.com/Rionquosue/rirytools_vpm).

This tool is written with machine assistance.

main contains only stable tools. beta contains untested or unreviewed code, betastaging contains code that is getting staged for beta but not quite ready for beta yet.
