# RiryTools

Source of `com.riry.rirytools`, editor-only workflow tools for Unity 2022.3 LTS.

- [`com.riry.rirytools`](com.riry.rirytools): the package. Its [README](com.riry.rirytools/README.md) describes every tool.
- [`Docs~`](Docs~): tutorials and design notes.

Install it from the VRChat Creator Companion: **Settings > Packages > Add Repository** and enter
`https://rionquosue.github.io/rirytools_vpm/index.json`.

Every push to `main` is published there as a new version, and every push to `beta` as a
beta, by [Rionquosue/rirytools_vpm](https://github.com/Rionquosue/rirytools_vpm). See
[VPM publishing](Docs~/design/vpm-publishing.md).
