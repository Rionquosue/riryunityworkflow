# RiryTools

Source of `com.riry.rirytools`, editor-only workflow tools for Unity 2022.3 LTS.

Overall structure of this repository is defined in [filestructure.md](docs/filestructure.md)
menu structure is defined in [menustructure.md](docs/menustructure.md)
Rules for how to code for or maintain this repository are in [instructions](docs/instructions)

this repository contains two major components.
1. The main Rirytools codebase
2. The face tracking emulation playback codebase

Install it from the VRChat Creator Companion: **Settings > Packages > Add Repository** and enter
`https://rionquosue.github.io/rirytools_vpm/index.json`.

All documentation in this directory is stored as markdown and will be used to publish more readable documentation [here](`https://github.com/Rionquosue/rirytools_vpm`)
