# RiryTools

This folder belongs to the RiryTools package (`com.riry.rirytools`).

- Files the package needs inside `Assets` are unpacked here. A file that
  already exists is never overwritten, so your edits survive package updates.
  Delete a file to get the package's copy back.
- Tools save generated assets here when there is no better place, for example
  Constraint Train clips and `_ROOT` prefab variants of read-only prefabs.
- Shader applets will live here.
