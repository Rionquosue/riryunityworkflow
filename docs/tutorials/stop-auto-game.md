# Tutorial: Stop Auto Game

Stop entering Play Mode from switching to the Game view.

**Tools > RiryTools > Stop Auto Game** is on by default (the menu shows a
check mark). About a tenth of a second after Play Mode starts, the
windows that had focus get it back from the Game view. If Play Mode opened a Game
view because the layout had none, it is closed when Play Mode ends, unless it was
one of the windows that had focus.

Choose the entry again to turn it off; the Console confirms the change. The
setting is per user and applies to every project on this computer.
