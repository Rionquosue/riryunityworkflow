# Tutorial: Play Mode Windows

Stop entering Play Mode from pulling the Game view to the front.

## Keep your tabs in front

**Tools > RiryTools > Play Mode > Keep Tabs in Front** is on by default (the
menu shows a check mark). When Play Mode starts, the tabs that were in front
come back to the front, and the window you were using keeps focus. If Play Mode
opened a Game view because the layout had none, it is closed again when Play
Mode ends.

Choose the entry again to turn it off.

## Close the Game view right away

Turn on **Tools > RiryTools > Play Mode > Close Game View Opened by Play Mode**
to close such a Game view as soon as Play Mode starts, for example when you
only watch the Scene view.

Both settings are per user and apply to every project on this computer.
